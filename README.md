# ds_exp2 — Understanding of the Data Handling Technique with Programming Exercise

**Dataset:** [`Sub_Division_IMD_2017.csv`](./Sub_Division_IMD_2017.csv) — IMD subdivision-wise monthly rainfall (4188 records, 36 subdivisions, 1901–2017).

**Use case:** KJS-AGR-01 — AI Irrigation Advisory System

## What's covered
Reading & exploring the dataset, null handling/imputation, sorting & filtering, frequency counts, `loc`/`iloc` indexing, conditional row access, min/max, `groupby` + aggregation, a derived column, correlation, Min-Max normalization, and merging/concatenation.

## Files
- `exp2_data_handling.py` — standalone script
- `EXP2_Data_Handling_16014324020.ipynb` — notebook with output
- `EXP2_notebook.pdf` — notebook as PDF
- `Sub_Division_IMD_2017.csv` — dataset

## Key finding
Monsoon (JJAS) rainfall correlates **0.94** with ANNUAL rainfall.
